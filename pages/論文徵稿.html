徵稿規範

徵稿主題：

  • Computer Graphics (Rendering, Modeling, Animation, etc.)
  • Scientific / Information Visualization
  • Augmented / Mixed / Virtual Reality
  • Image / Video / Audio Processing
  • Human-Computer Interaction
  • Others (any related topics are welcome)

投稿時程：

  • 截止收稿日：5月31日 6月12日(星期三)
  • 接收通知日：6月14日 6月19日(星期三)之前
  • 論文定稿日：6月21日 (星期五)

論文格式：

  • Microsoft Word (下載)
  • LATEX (下載)
    • 內容中英文皆可
    論文頁數以八頁內為原則


投稿連結

  • 請先至 EasyChair 註冊取得帳號及密碼，方可進行投稿作業。
  • 請注意，投稿至 CGW2025 的論文須為全新未經發表的論文，經審查後錄取之論文內容將只會在大會上由報告者自行公開，不會收錄於網頁或是會議手冊上。
  • 若有已經發表的論文想於大會上與聽眾分享，請來信至 xxx@ntut.edu.tw 通知大會共同主席，無需經過投稿與審查程序。
  • CGW2025 的論文獎項採分流制度，已經發表與未經發表的論文將分開評選。
